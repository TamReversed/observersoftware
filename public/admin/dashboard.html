Application Changelog

December 28, 2025

Application Review & Cleanup

Issues Fixed:

  • Stars not visible from blog: Page transitions now skip both TO and FROM blog/contact pages.
  • Changelog tab layout: Improved tab layout with flex-wrap for smaller screens.
  • Debug logging removed: Cleaned up console.log statements from production code.
Files: page-transitions.js, skeletons.js, products.js, home.js, admin.css
December 28, 2025

WebAuthn PublicKey Format Fix (COSE vs SPKI)

Issue: Passkey login failing with cosePublicKey.get is not a function

Root Cause: Code was using SPKI format publicKey instead of COSE format required by SimpleWebAuthn v11+.

Fix: Updated to use registrationInfo.credential.publicKey (base64url COSE key).

Files: services/webauthnService.js
December 28, 2025

WebAuthn RP ID Mismatch Fix

Issue: Passkey login failing with Unexpected RP ID hash

Root Cause: Registration used dynamic origin but login used static config value.

Fix: Login now derives RP ID from request origin, matching registration.

Files: controllers/authController.js
December 28, 2025

WebAuthn Authentication Fix

Issue: input.replace is not a function error during passkey login.

Root Cause: SimpleWebAuthn v10+ expects base64url strings, not Buffers.

Fix: Pass credential IDs as base64url strings directly.

Files: services/webauthnService.js
December 28, 2025

Blog Script Loading Fix

Issue: Identifier 'isDevelopment' has already been declared

Root Cause: Debug code was re-loading blog.js causing duplicate declarations.

Fix: Removed duplicate script loading and cleaned up debug code.

Files: public/blog.html, public/scripts/blog.js
December 28, 2025

JSONB Serialization & Blog Posts Migration

Issue: Blog posts not appearing on production site.

Root Cause: posts.json excluded from git, not available for Railway migration.

Fix: Updated .gitignore to track posts.json for database migration.

Files: .gitignore, data/posts.json
December 28, 2025

Product Modal & Screenshot Display Fixes

Issue: Product modals not opening, screenshots not displaying.

Root Cause: Canvas intercepting clicks; screenshot paths not normalized.

Fix: Added pointer-events: none to canvas; improved URL handling.

Files: styles.css, products.js, home.js
December 28, 2025

Database Mode for All Controllers

Issue: Controllers hardcoded to JSON instead of PostgreSQL.

Root Cause: Controllers not checking database config flag.

Fix: All controllers now use DbService or DataService based on config.

Files: postsController.js, workController.js, authController.js, initService.js
